# Detection Clustering and Electrode Area Estimation

This section contains the MATLAB implementation for electrode area estimation and final electrode detection clustering.

## Files

### 1. `Ground_Truth_Area_Estimation.m`

This script estimates the approximate surface area of each ground-truth electrode region on the head mesh.

The estimated electrode areas are later used as prior information in the detection pipeline to filter unrealistic surface patches.

#### Main Steps
- Load ground-truth electrode locations
- Extract electrode surface regions
- Compute mesh patch areas
- Save area measurements for later processing

#### Output
The script generates estimated electrode area statistics that are used in the detection stage.

---

### 2. `Detection_Clustering.m`

This script performs the main electrode detection and clustering pipeline.

Detected surface patches from multiple surfaces are combined and clustered to produce a single representative point for each electrode candidate.

The final detected electrode positions are:
- compared against the ground truth,
- evaluated using localization metrics,
- and used for the subsequent registration stage.

#### Main Steps

1. Neural Network Prediction Loading
- Loads predicted electrode vertices generated by the neural network classification stage.
2. Surface Region Clustering
- Groups connected predicted mesh regions using face connectivity.
3. Area-Based Filtering
- Filters detected surface patches using the electrode area statistics estimated from the training dataset (using Ground_Truth_Area_Estimation code).
4. Cross-Surface Projection
- Projects detected regions across neighboring surfaces to improve consistency and robustness.
5. DBSCAN Clustering
- Clusters nearby detections and represents each cluster using a single centroid point as the final electrode detection.
6. Ground Truth Comparison
- Compares the final detected electrode positions with manually labeled ground truth electrode locations.
7. Registration Preparation
- The final detected electrode positions are used as input for the subsequent electrode registration stage.

---

#### Final Output
- Final detected electrode positions
- True positive / false positive analysis
- Electrode centers for registration

---

## Notes

- Surface meshes are represented using vertices and faces.
- All coordinates are processed in 3D Cartesian space.
- DBSCAN is used to merge nearby detections across multiple surfaces.
- Ground-truth area estimation is used to suppress unrealistic detections.
