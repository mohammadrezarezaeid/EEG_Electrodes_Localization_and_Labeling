# Ground Truth Transformation (MNI → SCS)

This module converts manually labeled electrode positions from **MNI space** to the **SCS (Subject Coordinate System)** using transformation matrices generated by Brainstorm.

---

## Overview

Manual electrode annotations are initially defined in MNI space. However, since Brainstorm processes MRI data in SCS, all coordinates must be transformed to SCS for consistency.

This module performs that transformation for the entire dataset.

---

## Methods

The transformation is performed using affine matrices provided by Brainstorm during MRI normalization.

### Files

- Function: `Transfom2SCS.m`  
  - Applies the MNI → SCS transformation to electrode coordinates  

- Script: `GT2SCS.m`  
  - Processes all subjects and converts ground truth datasets to SCS  

---

## Precomputed Datasets

For convenience and reproducibility, transformed datasets are already provided:

- `Manual_labeling_SCS_64_elect`
- `Manual_labeling_SCS_256_elect`

These files contain ground truth electrode coordinates in SCS space and can be used directly without running the transformation step.

---

## Input

- Ground truth electrode positions in MNI space  
- Brainstorm transformation matrices (generated during normalization)

---

## Output

- Ground truth electrode positions in SCS space  

---

## Notes

- Brainstorm internally operates in SCS, making this transformation necessary  
- Using a consistent coordinate system (SCS) ensures accurate geometric processing and alignment with extracted head surfaces  
- If needed, transformations can be inverted to map results back to MNI space  

For more details on coordinate systems, see:  
[Brainstorm Coordinate Systems Documentation](https://neuroimage.usc.edu/brainstorm/CoordinateSystems)
